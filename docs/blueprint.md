# **App Name**: Bharatmaan AI

## Core Features:

- Real-time AI Chat Interface: Enables users to send text messages and receive real-time, context-aware replies from the AI, displayed within a dynamic chat bubble interface and featuring a 'Bharatmaan AI is typing...' animation.
- Contextual Conversation Memory: The AI stores and leverages past interactions, user preferences, names, and goals to provide personalized and consistent responses across sessions.
- Adaptive AI Personality Tool: The AI's responses and conversational tone dynamically adapt as a tool based on perceived user mood and intent, offering specialized modes like emotional support, study assistance, or a friendly demeanor.
- Persistent Chat History & Controls: Users can save and access their complete chat history, with options to clear individual conversations, ensuring their interactions are retained through Firebase integration.
- User Profile & App Settings: A basic settings page for users to manage general application preferences and initial parameters for AI interaction, supporting a tailored and beginner-friendly experience.

## Style Guidelines:

- Primary color: A warm, sophisticated deep saffron-orange (#D18928) for a friendly and modern feel that evokes Indian inspiration, providing warmth in a dark environment.
- Background color: A very dark, subtle brown-grey with orange undertones (#2E261E) that forms a clean, futuristic backdrop, visibly harmonious with the primary color.
- Accent color: A vibrant, deep red-orange (#E53D20) that is analogous to the primary hue, used for calls to action, alerts, and other highlighting elements to provide an energetic visual pop.
- Primary font: 'PT Sans' (sans-serif) for all text elements, providing a modern, clear, and slightly warm aesthetic suitable for both headlines and body text in a professional yet friendly application.
- Use sleek, minimalist line-art style icons that transition smoothly with subtle fill animations, maintaining a clean and futuristic aesthetic that supports the app's professional feel.
- Implement a clean, spacious layout for the chat screen, featuring aesthetically pleasing rounded message bubbles and a persistently anchored bottom message input area for intuitive user interaction.
- Incorporate smooth, micro-interaction animations throughout the app, including fluid transitions for scrolling, engaging send button animations, and a subtle typing indicator to enhance the responsive and companion-like feel.
